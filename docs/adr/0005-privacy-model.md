# ADR-0005:隐私模型(用户主动触发 + 本地存储)

- **状态**:已接受(2026-08-13)
- **关联**:`docs/requirements/requirements.md` §3.5、§NFR-5

## 背景
插件会读取并发送文档内容至 AI 服务商,涉及公司敏感信息与合规风险。

## 决策
- 插件**不做后台扫描/常驻采集**,仅在用户点击某 AI 操作时提取并发送当前文档
- 发送前明示"内容将发送至 {provider}"确认;提供"本会话记住"选项降低打扰
- API Key 与配置仅存 `chrome.storage.local`,不出扩展、无任何遥测
- 卸载即无残留(除用户主动保留)

## 后果
- 正面:合规风险可控;用户信任度高
- 负面:每次使用多一次确认(可"记住本会话"缓解);无法支持"自动检测并处理"类体验
