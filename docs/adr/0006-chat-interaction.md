# ADR-0006:侧边栏对话式交互(多轮上下文)

- **状态**:已接受(2026-08-13)
- **关联**:`docs/design/design.md` §4.2、需求 FR-2

## 背景
M1 初版为"能力按钮 → 一次性结果区",用户无法对结果继续追问,且对"文档内容为空"等情况体验生硬(模型会反过来索要输入)。

## 决策
将侧边栏改造为**完整对话流 + 多轮记忆**:
- 消息列表(用户指令 / AI 回复),底部输入框 + 快捷能力 chips
- 首轮 user 消息 = 能力指令 + 文档内容(Markdown);追问为纯文本 user 消息
- background 按 capability 生成**稳定 system**,并透传 sidepanel 携带的完整历史;provider 流式回传
- 每条 AI 回复可复制 / 重新生成(重新生成 = 移除该条后用此前历史重发)
- 大文档截断、隐私确认(ADR-0005)、空内容提示保留

## 后果
- 正面:交互符合"AI 助手"直觉;多轮追问可用;复制体验直接
- 负面:对话历史随请求透传,长对话 token 成本上升;system 在切换能力时变化,跨能力历史语义需模型自行协调
