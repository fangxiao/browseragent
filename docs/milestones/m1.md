## E2E 手动验证清单(需在浏览器实测)

1. **加载扩展**:Chrome → `chrome://extensions` → 开发者模式 → 「加载已解压的扩展程序」→ 选择 `output/chrome-mv3` 目录
2. **文档提取**:打开一篇飞书 docx 文档,打开 DevTools Console,确认 `[feishu-ai] extract result` 的 blockCount / textLength / extractionRate;检查提取的 Markdown 是否包含标题、列表、表格
   - 若 `extractionRate < 0.8` 或有 warnings,记录现象以便调整 `src/utils/platform/feishu/extract.ts`
3. **配置 AI 服务**:点击侧边栏「设置」→ 新增服务(推荐 DeepSeek,填 API Key)→ 设为当前
4. **需求评审**:打开需求文档 → 侧边栏选「AI 评审」→ 确认发送 → 观察流式输出(应含结构/可测性/一致性/风险分类)→ 复制结果 → 粘贴回文档
5. **周报补全**:打开半成品周报 → 「AI 补全」→ 确认区分「已有内容」与「【AI 建议】」
6. **通用能力**:任意文档选「摘要/润色」
7. **隐私确认**:「本会话记住」后再次执行应免确认
8. **大文档**:验证超过阈值时仅处理前 80 块

## 备注
- 飞书 DOM 结构可能与提取器假设不同,步骤 2 为最高优先级验证项
- 若需调整选择器,只需改 `extract.ts`,其余模块不受影响(适配器隔离)
