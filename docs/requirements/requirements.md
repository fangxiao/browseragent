# 需求文档:通用 AI 浏览器操作助手(Browser Agent)

> 文档版本:v2.1
> 状态:已实现(2026-08-14);统一交互式智能体,移除未经验证的细分场景概念,聚焦通用 DOM 挖掘与自动化操作能力。
> 上游决策:通用 AI 自主操作任意网页 DOM;统一对话交互;安全敏感动作前置确认。

---

## 1. 背景与目标

### 1.1 背景
前身为“飞书文档 AI 助手”(读文档 → 对话 → 写回)。用户核心诉求是 **AI 能直接操作任意网页**。故全面升级为**通用 AI 浏览器智能体**:用户输入自然语言目标,AI 自主规划并操作网页 DOM 完成任务。

### 1.2 目标
- 侧边栏对话式输入目标(统一自由对话流)
- AI 通过**通用浏览器工具集**自主操作当前页面:观察/查找/点击/输入/滚动/等待/数据提取/导航
- AI 多步自主规划:观察 → 规划 → 操作 → 再观察,直到完成或向用户询问
- **前置安全确认**:涉及提交、发布、删除、支付、跨域跳转等敏感动作前暂停,征得用户确认
- 飞书等特定平台不再做特殊对待,其能力完全融入通用工具集

---

## 2. 交互模式

- **单一对话流(统一智能体)**:不预设僵化场景分类,用户直接输入自然语言诉求(例如“帮我提取这个表格”、“帮我填写这个问卷”、“查一下这个产品的详情”)。
- **全过程透明可视**:展示 AI 推理思考(Thinking)、工具调用与结果卡片、内嵌安全确认弹窗、结构化 Markdown 输出(带 CSV 下载与复制)。
- **本地会话持久化**:本地安全存储历史会话,支持新开对话、切换与管理。

---

## 3. 核心能力与工具集

### 3.1 浏览器工具集(Content Script 提供,经消息安全执行)
- `readPage`:获取页面可交互元素树(深度语义折叠)+ 文本摘要
- `findElements`:按语义/关键词/角色精确查找匹配 DOM 元素
- `clickElement(selector)`:点击按钮、链接等,带高亮视觉反馈
- `typeInto(selector, text, clear)`:输入文本,兼容 input / textarea / select / checkbox / radio
- `scrollTo(selector, direction, iterations)`:滚动到指定元素或方向(支持连续滚动触发懒加载)
- `waitFor(selector, timeoutMs)` / `sleep(ms)`:处理异步页面渲染与等待
- `extractData(selector, format, columns)`:提取表格/列表数据,结构化行输出(支持列投影)
- `navigate(url)`:当前标签页导航(Background 执行,跨站触发安全确认)
- `getPageInfo`:获取当前页 URL、标题、语言等基本信息
- 高危工具(`evaluate` 任意 JS):默认禁用,可配置开启

### 3.2 AI 规划(Agent Loop)
- LLM **Function Calling / Tool Use**:流式思考 → 解析工具调用 → 执行工具 → 结果回填 → 自主循环
- 循环上限(25 步)、超时兜底、随时手动停止

---

## 4. 安全规范(重点)

- **敏感动作前置拦截**:点击“提交/发布/保存/删除/支付/下单”类按钮、密码框输入、离开当前站点的跨域导航均强制要求用户确认。
- **高危代码执行隔离**:`evaluate` 默认关闭。
- **隐私保护**:页面数据仅发送给用户配置的 LLM Provider,不私自回传任何第三方。

---

## 5. 验收与非功能要求

- 工具执行可靠,失败时将错误原因回填给 AI 自主纠错与重试。
- 纯逻辑层(DOM 树折叠、数据提取、表格重组、安全策略判定、状态机)完全解耦并具备完整的单元测试覆盖。
